# 滑动动画方案 V2

## 设计原则

一划是快速清理工具，核心体验是**决策速度**。动画服务于决策，不是装饰。

**一张牌，永远居中。**

交互模型是牌堆：用户手里拿着最上面那张，后面一叠等着。扔掉一张，下面的牌自然露出；拿回一张，它盖在当前牌上面。

## 方向定义

本文统一使用用户手势方向描述：

| 用户动作 | 业务语义 |
|----------|----------|
| 从右往左划 / 左划 | 下一张 |
| 从左往右划 / 右划 | 上一张 |
| 上划 | 加入待删除队列 |
| 下划 | 恢复最近误删 |

## 四个方向，两种模式

### 模式 A：当前牌飞走，下面的牌露出（左划 / 上划）

手势驱动当前牌，牌跟手移动，松手过阈值后朝该方向飞出。下面的牌一直在那里，不做任何入场动画，自然露出。

| 方向 | 语义 | 视觉动作 |
|------|------|----------|
| 左划 | 下一张 | 当前牌飞出左侧 |
| 上划 | 加入待删除队列 | 当前牌飞出顶部 |

### 模式 B：一张牌从对应方向盖回来（右划 / 下划）

手势只是触发器，不移动当前牌。目标牌从对应方向滑入 / 落下，直接盖住当前牌。当前牌不做动画，被盖住即消失。

| 方向 | 语义 | 目标牌从哪里来 |
|------|------|----------------|
| 右划 | 上一张 | 从左侧滑入 |
| 下划 | 恢复最近误删 | 从顶部落入 |

## 对称关系

```text
        ↓ 恢复（从上方盖回）
← 上一张（从左侧盖回）  [照片]  下一张（飞出左侧） →
        ↑ 删除（飞出顶部）
```

飞走的方向和回来的方向完全镜像：

- 左划飞走 ↔ 右划盖回：都走左侧
- 上划飞走 ↔ 下划盖回：都走顶部

## 动画参数

| 动作 | 时长 | 运动曲线 | 说明 |
|------|------|----------|------|
| 飞出（左 / 上） | 150ms | EaseIn | 决断感，快出 |
| 盖入（右 / 下） | 200ms | EaseOut | 落定感，轻缓收尾 |
| 拖动回弹 | 200ms | Spring | 未过阈值时弹回 |

飞出只做**位移**，不缩放、不淡出。盖入只做**位移**，不缩放、不淡入。

例外：上划拖动过程中，当前牌允许随距离轻微缩小，最多缩至 `0.85x`。这是拖动反馈，不是飞出动画本身。

## 拖动反馈

- 仅左划 / 上划响应实时跟手。
- 右划 / 下划不移动当前牌，只在松手过阈值后触发盖入。
- 上划拖动中，牌随拖动距离轻微缩小，最多缩至 `0.85x`。
- 触发阈值：`72px`。
- 方向锁定阈值：`10px`。
- 方向判断比例：主轴位移需要大于副轴位移的 `1.15x`。

## 与 V1 的主要差异

| 项目 | V1 | V2 |
|------|----|----|
| 左右翻页 | 三张联动分页 | 单张，左划飞走 / 右划盖回 |
| 删除后入场 | 下一张从右侧滑入 | 不做入场，直接露出 |
| 恢复动画 | 当前牌右移 + 误删牌从上落 | 只有误删牌从上落，当前牌不动 |
| 渲染数量 | 同时渲染三张卡片 | 常态只渲染一张，动画期间加一张 animatedCard |
| 手势区分 | 水平/垂直轴分页模型 | 四方向统一角度判断 |

## 实现结构

```text
SwipeStage
├── basePhoto（当前牌 / 盖入动画期间的被覆盖牌）
└── animatedCard（飞出或盖入的牌，仅动画期间存在）
```

关键数据结构：

- `AnimatedCard(photo, motion, startX, startY)`：携带动画起点，飞出从 `dragX` / `dragY` 无缝起飞。
- `basePhotoDuringCoverIn`：盖入动画期间保持旧牌静止，动画结束后清空。
- `CardMotion.FlyToLeft`：左划下一张。
- `CardMotion.FlyToTop`：上划加入待删除队列。
- `CardMotion.CoverFromLeft`：右划上一张。
- `CardMotion.CoverFromTop`：下划恢复最近误删。

手势逻辑：

1. 判断拖动方向。
2. 左 / 上：当前牌跟手 → 过阈值 → 先更新状态 → 再播放飞出动画。
3. 右 / 下：当前牌不跟手 → 过阈值 → 先更新状态 → 再播放盖入动画。

状态变更**在动画开始前**发生，动画只做视觉表现。

## 已知偏差 / 待处理

| 项目 | 当前情况 | 影响 | 优先级 |
|------|----------|------|--------|
| 删除最后一张 | 业务状态可能让 `SwipeStage` 提前卸载 | 最后一张飞出动画可能被截断 | P0 |
| 拖动回弹 | 需要确保 X/Y 两个方向都结束后再释放手势锁 | 快速连续滑动可能出现跳动 | P0 |
| 左划到末尾 | 卡片完全不动，无阻尼 | 边界感略生硬 | P2 |
| 上划松手飞出 | 拖动缩放态到飞出位移态可能略不连续 | 视觉细节问题 | P1 |
