# 滑动动画方案 V2

## 设计原则

这是一个快速清理工具，核心体验是**决策速度**。动画服务于决策，不是装饰。

**一张牌，永远居中。**

交互模型是牌堆：用户手里拿着最上面那张，后面一叠等着。  
扔掉一张，下面的牌自然露出；拿回一张，它盖在当前牌上面。

---

## 四个方向，两种模式

### 模式 A：当前牌飞走，下面的牌露出（左划 / 上划）

手势驱动当前牌，牌跟手移动，松手过阈值后朝该方向飞出。  
下面的牌一直在那里，不做任何入场动画，自然露出。

| 方向 | 语义 |
|------|------|
| 左划 | 下一张（当前牌飞出左侧） |
| 上划 | 删除（当前牌飞出顶部） |

### 模式 B：一张牌从对应方向盖回来（右划 / 下划）

手势只是触发器，不移动当前牌。  
目标牌从对应方向落下 / 滑入，直接盖住当前牌。当前牌不做任何动画，被盖住即消失。

| 方向 | 语义 | 目标牌从哪里来 |
|------|------|----------------|
| 右划 | 上一张 | 从左侧滑入 |
| 下划 | 恢复误删 | 从顶部落入 |

---

## 对称关系

```
        ↓ 恢复（从上方盖回）
← 上一张（从左侧盖回）  [照片]  下一张（飞出左侧） →
        ↑ 删除（飞出顶部）
```

飞走的方向和回来的方向完全镜像：

- 左划飞走 ↔ 右划盖回（都走左侧）
- 上划飞走 ↔ 下划盖回（都走顶部）

---

## 动画参数

| 动作 | 时长 | 运动曲线 | 说明 |
|------|------|----------|------|
| 飞出（左/上） | 150ms | EaseIn | 决断感，快出 |
| 盖入（右/下） | 200ms | EaseOut | 落定感，轻缓收尾 |
| 拖动回弹 | 200ms | Spring | 未过阈值时弹回 |

飞出只做**位移**，不缩放、不淡出。  
盖入只做**位移**，不缩放、不淡入。

---

## 拖动反馈

- 手指拖动时，牌实时跟手（仅左/上方向响应拖动；右/下方向不跟手，手势只做触发）
- 上划拖动中，牌随拖动距离轻微缩小（表达"即将离开"的预期反馈），最多缩至 0.85x
- 阈值：72px

---

## 与 V1 的主要差异

| 项目 | V1 | V2 |
|------|----|----|
| 左右翻页 | 三张联动分页（Apple Photos 风格） | 单张，左划飞走 / 右划盖回 |
| 删除后入场 | 下一张从右侧滑入 | 不做入场，直接露出 |
| 恢复动画 | 当前牌右移 + 误删牌从上落 | 只有误删牌从上落，当前牌不动 |
| 渲染数量 | 同时渲染三张卡片 | 只渲染一张（+ overlay） |
| 手势区分 | 需要区分水平/垂直轴 | 四个方向统一，角度判断 |

## 实现结构

```
SwipeStage
├── basePhoto（当前牌 / 盖入动画期间的被覆盖牌）
└── animatedCard（飞出或盖入的牌，仅动画期间存在）
```

关键数据结构：
- `AnimatedCard(photo, motion, startX, startY)` — 携带动画起点，飞出从 dragX/dragY 无缝起飞
- `basePhotoDuringCoverIn` — 盖入动画期间保持旧牌静止，动画结束后清空

手势逻辑：
1. 判断拖动方向（角度锁定，阈值 10px）
2. 左/上：当前牌跟手 → 过阈值（72px）→ 更新状态 → 飞出动画
3. 右/下：不跟手，纯触发 → 更新状态 → 盖入动画

状态变更**在动画开始前**发生，动画只做视觉表现。
