# 滑动动画方案 V2

## 当前交互真相

| 用户动作 | 业务语义 | 视觉反馈 |
|---|---|---|
| 从右往左划 / 左划 | 下一张 | 当前牌向左飞出，下一张自然露出 |
| 从左往右划 / 右划 | 上一张 | 上一张从左侧盖回来 |
| 上划 | 加入待删除队列 | 当前牌向上飞出 |
| 下划 | 恢复最近误删 | 最近误删牌从顶部盖回来 |

核心原则：一张牌，永远居中。业务状态先更新，动画只做视觉反馈。

> P0 上架门禁和问题状态只维护在 `docs/RELEASE_BLOCKERS_REVIEW.md`。本文只维护滑动交互和动画规格，不单独维护 P0 状态。

## 动画模型

### 当前牌飞走

用于左划和上划。

- 左划：当前牌飞出左侧。
- 上划：当前牌飞出顶部。
- 下一张牌不做入场动画，直接自然露出。

### 目标牌盖回来

用于右划和下划。

- 右划：上一张从左侧滑入并盖住当前牌。
- 下划：最近误删牌从顶部落入并盖住当前牌。
- 当前牌不跟手移动，只作为被覆盖背景。

## 参数

| 动作 | 时长 | 曲线 |
|---|---:|---|
| 飞出 | 150ms | EaseIn |
| 盖入 | 200ms | EaseOut |
| 未过阈值回弹 | Spring | 等 X/Y 两个方向都结束 |

手势阈值：

- 触发阈值：`72px`
- 方向锁定阈值：`10px`
- 主轴位移需要大于副轴位移的 `1.15x`
- 上划拖动反馈最多缩小到 `0.85x`

## 实现结构

```text
SwipeStage
├── basePhoto：当前牌 / 盖入动画期间的被覆盖牌
└── animatedCard：飞出或盖入的牌，只在动画期间存在
```

关键状态：

- `AnimatedCard(photo, motion, startX, startY)`：保存动画牌和起点。
- `basePhotoDuringCoverIn`：盖入时保持旧牌静止。
- `keepReviewStageForAnimation`：终态切换前保活动画舞台。
- `lastReviewableState`：删除最后一张时保留最后一个可展示状态用于播完动画。

## 已实现的关键约束

### 回弹动画等待 X/Y 两个方向结束

`springBack()` 同时启动 X/Y 回弹，并通过 `joinAll(xJob, yJob)` 等两个方向都完成。清理逻辑放在 `finally`，避免取消后留下脏状态。

验收：

- 未过阈值的左滑 / 上滑会完整弹回原位。
- 快速连续轻滑不会出现卡片跳动、抽搐或错位。
- 回弹过程中再次触摸不会打断状态机。

### 删除最后一张时保活动画宿主

当业务状态切到 `AllQueuedForDelete`，但飞出动画还没结束时，父层继续用 `lastReviewableState` 渲染 `SwipeStage`。动画结束后再显示“所有照片已加入待删除队列”。

验收：

- 只剩最后一张时，上划删除会完整播放向上飞出动画。
- 飞出动画结束后再进入“所有照片已加入待删除队列”。
- 最后一张删除不会闪切、黑屏或直接跳状态。
